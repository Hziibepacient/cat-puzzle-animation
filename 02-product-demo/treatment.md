# Only Cats · 30 秒界面发布片

这支片接在已有剧情动画之后。第 0 帧显示 Only Cats 欢迎页，并用一行品牌文案交代这是一个校园猫咪社交 App。整片是横屏，手机保持在同一位置，屏幕里使用真实网页端操作。无旁白、鼠标光标或功能步骤字幕。

| 时间 | 真实操作 | 画面与接续 |
| --- | --- | --- |
| 0–4 s | 欢迎页的猫从字标周围走过。 | 字标与产品定位同时出现，直接开始 UI 段。 |
| 4–10 s | 打开相册、选择贴贴、填写图书馆门口，看到偶遇预览。 | Cilly 形象接住助手入口，预览出来时才引出贴贴的照片。 |
| 10–16 s | 滑动偶遇广场，打开贴贴的帖子并看留言。 | 延续同一只猫和同一个地点。 |
| 16–22 s | 从贴贴的档案开始，连续六次快滑顶部头像条，从第 2 条翻到第 26 条，最后停在兰花，保留「26 / 91」供阅读。 | 滑动时收起左边的照片，视线集中在头像条和随之切换的档案。 |
| 22–28 s | 进入阿禾的聊天，读到贴贴的消息，发送一条邀约。 | 现实动作落在“因为猫认识彼此”，用本地试玩数据。 |
| 28–30 s | 聊天保持可见，左边落到品牌字标和主张。 | 同一部手机从第一帧保留到最后。 |

**配乐**　Kevin MacLeod 的《Monkeys Spinning Monkeys》。把原曲的 144 BPM 调为 120 BPM，保留拨弦和长笛的音高，剪成 30 秒并在结尾淡出。打开偶遇详情时加入一声短拨音，聊天消息发出时加入两声轻音。曲目和授权见素材说明。

**审片**　0、8.9、13.2、20.8、26.4、29 s 检查真实状态与阅读区。逐一核对 4、10、16、22 s 的屏幕切换，并确认全片无前段剧情画面。
