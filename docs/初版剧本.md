# 猫咪 App 宣传视频 — Codex 交接文档

## 任务

为第一届农客松初赛提交，制作一个 3 分钟以内的演示视频。故事片 + 操作录屏结合，既要讲清楚产品是什么，也要让评委看到产品真实怎么用。

初赛提交截止：2026-11-22（周日）18:00。

## 产品背景

校园猫咪社交 App，以校园猫咪为共同话题促成人与人连接。React Native，只做前端、预留后端 API，前端已做好。

四个页面（按此顺序）：

1. 对话助手 Agent（名字：Cilly，小猫咪人格，可接大模型聊天；**唯一偶遇发布入口**：拍照识猫、手动给地点、预览确认后发布）
2. 偶遇广场（只浏览无发布按钮，可加好友，可删自己发布的）
3. 消息与好友（Telegram 式文字聊天，好友申请通过后才能聊；无群聊、语音、图片聊天）
4. 猫咪图鉴（展示猫咪档案 + 订阅；不做"最近偶遇"；不做点赞、投票、评论）

## 视频概念

一男四线，同一个结局：男生通过 App 认识女神，一起喂猫，幸福快乐地生活在一起。

### 第一段：偶遇广场

男生下载 App，刷偶遇广场，看到女神发的偶遇猫咪动态，赶过去，和女神一起喂猫。

### 第二段：好友 + 订阅猫

男生下载 App，加了女神好友，订阅了女神。女神一发布偶遇猫咪消息，他就收到提醒，赶过去，和女神一起喂猫。

### 第三段：图鉴 + Cilly

男生查图鉴，了解到猫咪喜欢吃什么。每次遇到猫咪，他就拍下来，问 Cilly"这是什么猫"。Cilly 告诉他之后，他跟女神讲得头头是道，女神觉得他非常了解猫、跟她有一样的爱好。

### 第四段：Agent 对话发帖（核心功能）

男生在校园里偶遇一只猫，打开 App 跟 Cilly 对话几下，就把偶遇帖子发出去了。女神看到这条帖子，赶过来，两个人一起喂猫。

这段是重点：Agent 对话发帖是 App 唯一的发布入口，也是区别于普通猫咪图鉴产品的核心。
